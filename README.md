# API-REST-com-NodeJS
Criando API Rest com NodeJS acompanhado as aulas do curso de NodeJS da Rocketseat

# Base do Projeto (RF, RN, RNF)
### Requisitos Funcionais
- O usuário deve poder:   
    - [ ] Criar uma nova transação;   
    - [ ] Obter um resumo da sua conta;   
    - [ ] Listar todas as transações que já ocorreram;   
    - [ ] Visualizar uma transação única;   

### Regras de Negócio
- A transação pode ser de dois tipos:   
    - [ ] Crédito: Somará ao valor total;   
    - [ ] Débito: Irá subtrair do valor total;   
   
- [ ] Deve ser possível identificar o usuário entre as requisições;   
- [ ] O usuário só pode visualizar transação que ele criou;
